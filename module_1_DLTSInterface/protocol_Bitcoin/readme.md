# Bitcoin DLTs interface module components
The rpesented tools allow to parse the raw blockchain data synched from bitcoin core into the defined custom format.

## BTCParserBTCJ16

Java parser from blk*****.dat files to custom format.

## CommonInputsClustering
Java code for multi-input clustering heuristic on Bitcoin (needed to support the User Graph model).

## PandasBTCDatasetCreator
Java project to parse the data in our custom format and produce data in tablular format to be uploaded on pandas or similar data analysis tools.
